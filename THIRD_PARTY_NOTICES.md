# Third-party components

- noVNC 1.5.0: MPL-2.0, https://github.com/novnc/noVNC. The generated bundle carries a license notice; the full npm license is served as `/novnc-LICENSE.txt`. Unmodified upstream sources are available from the pinned npm package and repository tag; the source map also embeds the bundled source files.
- VirtualGL 3.1.4: upstream licenses, https://github.com/VirtualGL/virtualgl. License files are installed by the upstream Debian package under `/opt/VirtualGL`.
- TigerVNC, XFCE, Mesa, PulseAudio, Ubuntu packages: respective upstream licenses, included in the desktop image's `/usr/share/doc` directories.
- Rust dependencies: Cargo.lock lists exact versions; their upstream licenses apply.

Bilskirnir's MIT license applies to its own source. These third-party components retain their upstream licenses.
